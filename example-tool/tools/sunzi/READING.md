# Reading order (example equipment)

1. In the dictionary, start with [[势]] [[形]] [[虚实]] — these three carry the frame of the whole book.
2. Then [[诡道]] [[奇正]] [[迂直之计]]: the moves the other side will make.
3. Last [[庙算]] [[知彼知己]] [[反间]] [[不战而屈人之兵]]: what the owner himself should be doing.
4. In the corpus, by chapter: 始计 → 军形 → 兵势 → 虚实 → 军争; open the rest only when a situation names them.
