## 原理
「能而示之不能」是[[诡道]]的第一条；示弱是让你替对方出力。判断不是「对方穷不穷」，是「让步换来了什么算数的东西」——书面交期、付款条件、违约条款（主人的 J4）。看[[虚实]]：对方示弱时，他的实在哪里。

## 问题
- 这次让步换到了什么书面的东西？默认：没有 → 不让。
- 对方的「没预算」能不能核？默认：不能 → 当作招，不当作事实。
- 你现在是不是在情绪高点（愧疚、着急）？默认：是 → 今天不回。

## 练习
- 写下对方近三次示弱之后各得到了什么。

## 动作
- 只对主人自己：把让步条件改写成「换 X 才让」再回复；今天不回复。

## 信号 / 反模式 / 退出条件
- 信号：示弱之后紧接着一个具体数字。
- 反模式：为了「不近人情」让出没有交换的让步。
- 退出：对方把交换写进合同 → 转到正常让步节奏。
